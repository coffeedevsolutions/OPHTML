## findings

- **Closed by the 0.7.0 cut.** This read "`__version__` is `0.6.0.dev0` while every page carries `version: 0.6.0`" -- a mismatch that is normal mid-cycle, because the page stamp names the published version and `__version__` names the tree. At a release the two meet: both are `0.7.0`. The page pastes the real `--version` output either way.
- The usage line printed by `ps2ui-fontgen` names `python -m ps2ui_bake.fontgen`, not the installed command (fontgen.py:154). Cosmetic; the page documents the argv shape, not the usage string.
- `DEFAULT_CHARSET` still contains U+00A0 as the first character of the literal (fontgen.py:25) after the comment on lines 23-25 describes it as the character that once impersonated the space. Harmless to layout because `&nbsp;` collapses to a space in the compiler (ARCHITECTURE.md D7), but the charset is 115 glyphs rather than the 114 the comment implies.
- `ps2ui fontgen` creates `--out-dir` before the first face is measured, so a run stopped by a missing `uharfbuzz` leaves an empty directory behind (ps2ui.py:355).
- `packages/layout/bin/ps2ui-dev.js` and `packages/layout/bin/ps2ui-layout.js` show as modified in `git status` at the start of this run. Not touched by this agent.
