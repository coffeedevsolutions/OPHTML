## follow-up

Not in the drift table, found while verifying:

1. `position` is listed in `GEOMETRY_PROPS` (packages/layout/src/css.js:26) but
   has no `case` in `applyDeclaration`, so it can never be applied. The entry
   only changes which diagnostic an author sees: inside a `:focus` rule
   `position` is refused as a geometry change, and outside one it warns as an
   unsupported property. Either drop it from the set or give it a `case` that
   errors by name.
2. A `:focus` compound that matches no focusable element is dropped without a
   diagnostic (packages/layout/src/css.js:158). Writing `.panel:focus` where
   `.panel` carries no `focusable` attribute compiles clean and paints nothing,
   which is the same output as a typo in the class name. The brief for this page
   expected a warning here; none is emitted.
3. `letter-spacing`, `text-align` and `text-overflow` inside a `:focus` rule are
   accepted and then discarded at emission (packages/layout/src/paint.js:138-158
   reads `box.style`, never `box.focusStyle`). `font-weight` in the same position
   is honoured for the drawn face but not for the measurement. All four are
   candidates for `GEOMETRY_PROPS`, or for a warning of their own.
