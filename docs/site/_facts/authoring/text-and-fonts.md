## findings

- `packages/layout/src/text.js:45` states that the `To` pair is "-5px at 32px
  and 0px at 11px". The first half is right; the second is not. `kern_px(-170,
  11)` is -2, and -170 units rounds to 0 only at sizes of 2px and below, since
  `floor(-170 * size / 1000 + 0.5)` reaches 0 when `size <= 2.94`. The page
  states the measured values. The comment's point stands, the example does not.
  The brief for this page repeats the comment's number.
- `~` expands in a manifest's `metrics` path on the baker's side
  (`cli.py:122`) and not on the compiler's (`index.js:110`), so one manifest
  can load in `ps2ui-bake` and fail in `ps2ui-layout`. Recorded as
  `fonts.manifest.metrics-tilde` and documented under Limits and errors.
- Parent facts file `_facts/reference/ir-format.md` marks
  `ir.schema.slot.single-line` as `code-only`, saying the scratch attempt never
  reached the throw. It is reachable: a 100px box holding `Shadow of the
  Colossus` at 14px raises it (see `text.slot-single-line`). Not a dispute, the
  parent fact is correct; only its status could be raised.
- `packages/layout/bin/ps2ui-dev.js` and `packages/layout/bin/ps2ui-layout.js`
  show as modified in `git status` at the start of this run. Not touched by
