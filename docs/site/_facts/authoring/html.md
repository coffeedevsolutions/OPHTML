## follow-up

`packages/layout/src/html.js:161` is dead code. `parseAttrs` (html.js:68-91) returns at
exactly one place, html.js:73, and only when `r.peek() === '>'` or `r.startsWith('/>')`.
The caller's `if (r.startsWith('/>')) ... else if (r.peek() === '>') ...` covers both, so the
`else r.error(\`malformed tag <${tag}>\`)` on html.js:161 cannot run. Either delete it or
make `parseAttrs` return on a condition the caller does not already own.
